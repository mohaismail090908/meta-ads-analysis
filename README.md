# 📊 Meta Ads Campaign Performance & Marketing Analytics

## 📌 Project Overview
This project provides an end-to-end marketing analytics solution analyzing **Meta (Facebook & Instagram) Advertising Campaigns**. The objective is to evaluate campaign effectiveness, analyze conversion funnels, optimize ad spend allocation, and improve Return on Ad Spend (ROAS).

---

## 🎯 Key Business Questions Addressed
1. **Cost Efficiency**: What is the Cost Per Click (CPC) and Cost Per Acquisition (CPA) across different campaign types?
2. **Audience Engagement**: Which target demographics and ad creatives deliver the highest Click-Through Rate (CTR)?
3. **Conversion Funnel**: Where are potential customers dropping off in the marketing funnel?
4. **ROI Optimization**: How can marketing budget be redistributed to maximize return on investment?

---

## 🛠️ Tools & Technologies
- **Power BI**: Data Modeling, Interactive Dashboard Visualizations, Custom DAX Metrics.
- **Excel / CSV**: Raw Marketing Dataset Processing.
- **Git & GitHub**: Version Control & Project Documentation.

---

## 💡 Key Metrics & DAX Formulas Created
- **CTR (Click-Through Rate)** = `SUM(Clicks) / SUM(Impressions)`
- **CPC (Cost Per Click)** = `SUM(Spend) / SUM(Clicks)`
- **CPA (Cost Per Acquisition)** = `SUM(Spend) / SUM(Conversions)`
- **ROAS (Return on Ad Spend)** = `SUM(Conversion Value) / SUM(Spend)`

---

## 📈 Dashboard Features
- **Executive Summary**: High-level KPIs (Total Spend, Total Impressions, Conversions, ROAS).
- **Campaign Breakdown**: Deep-dive performance comparison across ad sets and campaign objectives.
- **Demographic & Placement Analysis**: Performance analysis by age, gender, device, and platform (Facebook vs. Instagram).
